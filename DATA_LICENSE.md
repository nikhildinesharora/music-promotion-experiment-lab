# Data license and attribution

This project uses the Last.fm Dataset - 1K users collected by Oscar Celma at
the Music Technology Group, Universitat Pompeu Fabra. The dataset contains
anonymized user, timestamp, artist, and track tuples collected through the
Last.fm API.

- Original project: http://ocelma.net/MusicRecommendationDataset/lastfm-1K.html
- Convenient 50-user Parquet release used by this project:
  https://github.com/eifuentes/lastfm-dataset-1K/releases/tag/v1.0
- Required attribution: https://www.last.fm/

The source data is distributed with Last.fm's permission for non-commercial
use. It is downloaded at runtime and is not covered by this repository's MIT
license. Review the source README and Last.fm terms before using the data.

The campaign assignment and post-exposure outcomes in this project are a
deterministic simulation. They are original generated data and do not describe
an experiment run by Last.fm, Spotify, or any other music service.
